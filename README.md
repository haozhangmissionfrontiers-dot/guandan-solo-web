# 惯蛋 · 单人网页版

这是独立的静态发布目录，仅包含浏览器单人练习版。每位访问者在自己的浏览器里与三位电脑玩家对局；这里没有好友房、账号系统、实时联机服务器或收费功能。

牌局存在访问者自己的浏览器本地存储里。清除浏览器数据或更换设备后，无法恢复进度。单人版为了驱动电脑玩家，整局状态也在本机浏览器内，因此界面虽不展示电脑手牌，却不能防止通过开发者工具查看数据。

首页不再选择难度。三位电脑玩家、实时出牌建议和盘后复盘统一使用难度四（DanLM V1），在浏览器后台线程运行。模型权重压缩存储，GitHub Pages 的首次网络传输（模型加推理组件）约 11 MB，之后可利用浏览器缓存。打开网页时先下载、初始化并检查模型，完成后才开放首页和牌桌；失败可重试。不需要远程推理服务或付费 API。继续旧存档时会将电脑切换到难度四，已发的牌不会改变。

轮到你时，“出牌建议”展示难度四评分最高的合法候选动作及根据可见牌面生成的参考理由；点选建议不会自动出牌。“出牌记录”中你自己的每一步可查看当时的模型候选和实际出牌评分。复盘只重建那一步之前可见的信息，不使用后来发生的牌或其他玩家隐藏手牌。模型分数不是胜率；参考理由是局面利弊分析，不是对模型内部评分原因的解释。

难度四只依据行动玩家自己的手牌与公开行动评分。网页版使用经过裁剪的合法候选集，因此其选择可能与参考 Python 智能体在完整候选集上的选择不同。DanLM 模型包含非商业使用限制，见 `models/DANLM-LICENSE`。开发仓库保留旧难度的历史对打实验，但旧难度及 DanZero 权重不再随网页发布。有限种子的模型对打结果不代表对真人的胜率。

牌桌下方直接显示当前一轮每位玩家的出牌和过牌顺序，并可展开回看本副此前各轮。手机上的全部手牌采用紧凑多行布局，不需要横向滑动。

源代码在独立开发目录 `Guandan-web` 的 `codex/web-version` 分支；本仓库只用于发布构建后的静态文件。面向中国大陆用户正式发行前，应独立核实网络游戏出版和运营要求。
