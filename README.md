# 惯蛋 · 单人网页版

这是独立的静态发布目录，仅包含浏览器单人练习版。每位访问者在自己的浏览器里与三位电脑玩家对局；这里没有好友房、账号系统、实时联机服务器或收费功能。

牌局存在访问者自己的浏览器本地存储里。清除浏览器数据或更换设备后，无法恢复进度。单人版为了驱动电脑玩家，整局状态也在本机浏览器内，因此界面虽不展示电脑手牌，却不能防止通过开发者工具查看数据。

开局时可分别设置三位电脑玩家为简单、难度一或难度二。难度一考虑剩余牌型和团队局势；难度二在残局依据公开信息抽样未知牌并模拟本副的团队升级结果。开发仓库中的固定发牌、交换座位对打验证了难度层级：难度一对简单 71/80 胜，难度二对简单 77/80 胜，难度二对难度一 56/80 胜。

源代码在独立开发目录 `Guandan-web` 的 `codex/web-version` 分支；本仓库只用于发布构建后的静态文件。面向中国大陆用户正式发行前，应独立核实网络游戏出版和运营要求。
